# Delhivery Route Intelligence: React Frontend Dashboard

This directory houses the React + TypeScript frontend dashboard for the **Delhivery Route Intelligence Platform**. Built on Vite, it provides a full-screen, high-performance dark-theme UI featuring interactive 3D graphs, congestion scorecards, ETA predictors, and transportation route advisors.

---

## ⚙️ Core Scripts

### 1. Development Server
Launches the asset pre-copier and starts the Vite development server with Hot Module Replacement (HMR):
```bash
npm run dev
```

### 2. Production Compilation
Runs the pre-copier, checks TypeScript types, and compiles minified bundles into the `dist/` directory:
```bash
npm run build
```

---

## 📦 Static Asset Copier: `copy-assets.js`

Since the interactive network graph files (`delhivery_network_map.html` and `delhivery_interactive_network_IDS.html`) are generated by Python scripts outside the React folder, we use `copy-assets.js` to automatically keep them in sync.

Every time `npm run dev` or `npm run build` is executed, the script copies:
* `frontend/delhivery_network_map.html` ➔ `public/delhivery_network_map.html`
* `frontend/delhivery_interactive_network_IDS.html` ➔ `public/delhivery_interactive_network_IDS.html`
* `backend/lib/bindings/utils.js` ➔ `public/lib/bindings/utils.js`

Vite then serves them locally from `public/` and packages them directly in the built production `dist/` directory for Vercel.

## ☁️ Vercel Deployment & SPA Routing: `vercel.json`

Vercel is configured using `vercel.json` to serve the compiled Vite build directory:
```json
{
  "cleanUrls": true,
  "outputDirectory": "dist",
  "rewrites": [
    { "source": "/(delhivery_network_map.html|delhivery_interactive_network_IDS.html|lib/bindings/utils.js)", "destination": "/$1" },
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
```

* **Clean URLs**: Enables clean URL navigation.
* **Rewrites**: Intercepts map HTML files and serves them directly as static HTML documents. Fallback requests route to `index.html` to support React Router single-page navigation.

## 🔮 Client-Side ML Simulation Fallback

When hosted statically on Vercel, the local FastAPI server (`http://localhost:8000`) is offline. The dashboard service [api.ts](src/services/api.ts) automatically falls back to client-side simulators mapping the actual python models:

1. **Random Forest Regressor Simulation**: Computes travel times by applying peak traffic multipliers (morning/evening peaks), route factors, detour ratios, and adding hub queue delays based on node centralities.
2. **Random Forest Classifier Simulation**: Evaluates SLA hours, cargo weight, transit distance, and corridor risk metrics to suggest Carting loops or FTL shipping containers.
3. **Database scorecard**: Feeds the scorecard, search directories, and KPI charts with all **1,657 real nodes** parsed from `hub_mappings.json`.
